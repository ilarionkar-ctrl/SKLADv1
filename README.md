# Склад: учёт полуфабрикатов (Android PWA + Google Sheets)

Мобильное приложение сотрудника склада по ТЗ от 05.11.2026: сканирование QR → форма перемещения → документ → Google Sheets в реальном времени; инвентаризация с выгрузкой в Excel.

## Состав
- `backend/Code.gs` — серверная часть (Google Apps Script), работает с таблицей: листы **Справочник**, **Журнал**, **Остатки** (по ТЗ) + **Зоны**, **Пользователи**, **Аудит**.
- `index.html, app.js, style.css, xlsx.js, sw.js, vendor/qrcode.js …` — приложение. Устанавливается на Android из Chrome («Добавить на главный экран»), работает как приложение, держит очередь документов при потере связи.

## Развёртывание (≈15 минут)
1. Создайте Google-таблицу. **Расширения → Apps Script**, вставьте `backend/Code.gs`, сохраните.
2. Обновите таблицу → в меню **Склад → Настроить таблицу** (разрешите доступ). Создадутся листы и зоны хранения (измените на листе «Зоны»: названия ларей, ответственные).
3. **Склад → Добавить / изменить пользователя** — заведите повара и кладовщика (логин, имя, пароль ≥ 6 символов, роль).
4. Заполните лист **Справочник**: Артикул · Наименование · Ед. изм. (кг/шт) · QR-код (можно пусто) · Мин · Макс · Категория.
5. Apps Script → **Развёртывание → Новое развёртывание → Веб-приложение**: «Выполнять от имени: я», «Доступ: все». Скопируйте адрес, заканчивающийся на `/exec`.
6. Выложите папку приложения на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages) — HTTPS обязателен для камеры. Адрес `/exec` впишите в `config.js` (`API_URL`) либо вводите на экране входа.
7. На телефоне откройте адрес в Chrome → «Добавить на главный экран».

## Как работает
- **Перемещение:** направление + место хранения → сканируйте QR → масса (поле или калькулятор) → «Добавить» → ещё позиции → «Отправить документ». Остатки по зоне и общий пересчитываются на листе «Остатки» (сгруппированы по категориям, внутри — по алфавиту; подсветка «ниже минимума»/«минус»).
- **Весовые штрих-коды** EAN-13 вида `2 PLU(5) граммы(5) к`: вес подставляется автоматически, PLU сопоставляется с артикулом/QR (без учёта ведущих нулей).
- **Инвентаризация:** выбор зоны, прогресс «посчитано из N», непосчитанные можно принять за 0; Excel (по алфавиту: учёт / факт / расхождение) скачивается на телефон. Галочка «Скорректировать остатки по факту» — по желанию.
- **Нет QR:** «Найти по названию» → «Добавить вручную» (новая позиция в «Справочник», артикул `Н-0001…`). Неизвестный QR можно сразу привязать к позиции или завести новую.
- **QR-коды:** привязка сканированием; печать этикеток (QR + название + артикул + дата) через системную печать Android на принтер 4BarCode; размер этикетки — в Настройках. Позиции без QR получают код = артикул.
- **Журнал/аудит:** каждая строка — автор, дата, тип, направление, зона; входы и правки справочника — на листе «Аудит». Повторная отправка того же документа не дублируется. Меню **Склад → Пересчитать остатки** восстанавливает «Остатки» из журнала.

## Безопасность
HTTPS; пароли хранятся только в виде соленого хэша; сессия 12 ч (подписанный токен); блокировка после 5 неверных попыток на 10 минут; записи под блокировкой (без гонок при одновременной работе).

## Не вошло / ограничения
- Прямая интеграция с iiko (документы в iiko) — ТЗ в разделе «Объём работ» требует Google Sheets, поэтому не делалась; номенклатуру из iiko можно выгрузить в «Справочник».
- Приложение — PWA, а не нативный APK (работает в Chrome на Android; нужен `BarcodeDetector`, есть в Chrome/Android). Ручной ввод кода работает всегда.
- Лист «Остатки» формируется автоматически — не редактируйте вручную.
- Тестировалось на имитации Google Sheets и в Chromium; на реальном телефоне камеру и печать на 4BarCode стоит проверить отдельно.
